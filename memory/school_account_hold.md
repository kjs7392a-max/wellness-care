로그인 「학교 계정」 관련 작업(개인 계정으로 바꾸기·인증 붙이기)은 **사용자가 직접 말할 때까지 보류**다(2026-10-19 사용자 「학교계정은 내가 말할때까지 보류야」).

**Why:** 사용자가 시점을 직접 정하겠다고 했다. 지금 로그인은 인증이 아니라 아이디 구분용뿐(`WellnessApp.tsx:662-666`)이라 글자만 바꾸면 안 되고, 인증 방식 선택이 먼저 필요하다.

**How to apply:** 먼저 제안하지 말고, 프리플라이트·「남은 일」 목록에도 올리지 않는다. 사용자가 꺼내면 재개 첫 질문 = 로그인 방식 선택(상세 `docs/worklog/2026-10-19.md` 맨 위).
