## 왜 이렇게
- 안내 문구는 영상 `currentTime` 이 아니라 **타이머 초**로 정한다 — 자동재생이 거부돼도 안내는 흘러야 한다.
- 1·3·5·10분 칩은 그대로. 「1분만 채워도 오늘 몫」이라는 화면 문구에 맞춰 영상도 1분 한 세트, 긴 분은 loop.

## 후속 (같은 날) — 영상 화면에서 타이머 제거 + 제안 하나로 고정
- `f02cfd1` 영상 항목 화면 = 제목·설명·영상·「영상을 따라 해보세요」·맨 아래 「시작하기」(→영상 재생, 재생 중엔 「마치기」). 분 칩·시계·"1분만 채워도" 문구 제거. 구간 안내는 영상 currentTime 기준.
- 제안 고정 = `suggestion.ts` `MVP_FIXED_SUGGESTION=true` → 시각·요일·직군 무관 「퇴근 전 어깨·목 풀기」. 원래 설계와 복원 절차는 `docs/decisions/2026-09-12-mvp-fixed-suggestion.md`.
- 검증: vitest 16/16(suggestion 5 신규 · 플래그 off 경로도 테스트) · tsc 0 · build · Chrome 실행(토요일 00시·행정 직군으로 들어가도 홈 제안이 「퇴근 전 어깨·목 풀기」, 시트에 칩·시계 없음, 「시작하기」 → `video.paused=false` + 「마치기」).

## 후속 2 — 「시작하기」가 잘리던 것 + 1분 뒤 정지
- 사용자 보고: 폰에서 맨 아래 「시작하기」가 2/3만 보임. 원인 = 영상 박스가 `aspect-ratio 9/16 + max-height 58vh` 고정이라 짧은 폰에서 열이 화면보다 길어짐.
- 수정 = 영상 박스를 `flex:1; min-height:0` 로 남는 높이만큼만(9:16 은 유지, 너비가 따라 줄어듦) · 열에 `min-height:0` · 간격 18→14. 실측(Chrome, 프레임 높이를 JS 로 바꿔가며): 844px → 버튼 바닥 798/822 · **640px → 594/618**(영상 189×335) 둘 다 화면 안.
- `loop` 제거. 끝나면 `onEnded` → 부모 `running=false, remaining=0` → 영상 정지·오버레이 「오늘 몫 완료」·버튼 「마치기」. 합성 `ended` 이벤트로 실측(정지·문구·버튼 전부 확인).
