## 왜 이렇게
- 안내 문구는 영상 `currentTime` 이 아니라 **타이머 초**로 정한다 — 자동재생이 거부돼도 안내는 흘러야 한다.
- 1·3·5·10분 칩은 그대로. 「1분만 채워도 오늘 몫」이라는 화면 문구에 맞춰 영상도 1분 한 세트, 긴 분은 loop.

## 후속 11 — 신체·마음 「컨디션」 카드 + 상세 시트
- 사용자 확정: 5단계(휴식 필요·조금 지침·보통·좋음·매우 좋음), 숫자 비노출, 단계와 변화만. 홈에 카드 2장 나란히 + 제안 한 줄, 상세 페이지 별도. 대화 내용은 재료로 안 씀(횟수만).
- `condition.ts`(순수): 재료 → 신호(−1/0/+1) → 합계 → 단계. 신체 = 몸풀기 횟수(≥3 +1 / 1~2 0 / 0 −1) + 움직인 시간 + 걸음(둘은 목업이라 0). 마음 = 무거운 결 비율(≥40% −1 / ≥20% 0 / 그 밖 +1) + 기록 일수(≥4 +1 / 2~3 0 / ≤1 −1); 대화 횟수는 단계를 바꾸지 않음; 위험어 뜬 주는 무조건 「휴식 필요」; 기록 0 이면 단계 없음. 변화 문장·제안(몸×마음 9조합)·근거 줄(횟수·일수만). 테스트 11.
- 화면: 홈 「신체 건강/마음 건강」 타일 아래 카드 2장(단계·↑↓·변화 문장) + 제안 → 누르면 「컨디션 상세」 시트(신체/마음 탭 · 이번 주 · 근거 3줄 · 최근 4주 이름만 · 제안+CTA · 위험 주엔 마음쉼 버튼). 지난주·최근 4주는 목업 상수 `CONDITION_HISTORY`.
- 온보딩 첫 장 "점수도 등급도 순위도 만들지 않아요" → "점수나 순위를 매기지 않아요"(단계가 생겨 등급 약속은 거짓이 되므로).
- Chrome 실측(목업+세션): 신체 「좋음 · ↑ 지난주 보통 → 이번 주 좋음」 · 마음 「보통 · 지난주와 같아요」 · 제안 "가볍게 몸을 풀며 유지해 보세요." = 사용자 예시와 일치. 상세 시트 근거·4주·CTA 확인.
- ⚠ 시연 기간엔 걸음·움직인 시간이 목업(평소 수준)이라 신체 단계는 몸풀기 횟수로만 움직인다.

## 후속 12 — 「종합 컨디션」 하나로 (사용자 정정)

## 후속 16 — 디렉팅에 근거 세우기 (사용자 "근거 있는 디렉팅이냐")
- 솔직한 답: 그림→결→문장은 내가 쓴 것이고 투사법 자체는 타당도가 낮다. 마무리 제안(컨디션 규칙)만 앱 근거가 있었다.
- 틀: 결 6종을 **정서의 원형 모델(Russell 1980, 각성×유쾌)** 사분면에 놓았다 — 활력 HP · 안정/연결 LP · 격동 HN · 무게/정지 LN. 그림은 매개이고 선택은 "지금 어느 사분면인가"의 자가보고. 우세 사분면 = 불쾌가 절반 이상이면 불쾌 쪽(HN/LN 중 다수, 동률은 저각성=휴식 우선), 아니면 유쾌 쪽.
- 제안은 사분면별 근거 있는 정서조절 전략만: HN → 각성 낮추기(3분 숨 고르기·이완 호흡) / LN → 아주 작은 행동 하나(행동활성화: 1분 기지개·복도 한 바퀴) / HP → 힘 쓸 곳(걷기) / LP → 유지·기록. 어제 신체가 낮으면 부담 낮은 판으로.
- 화면에 정직한 한 줄: "이 카드는 검사가 아니라, 지금 마음을 스스로 들여다보는 방법이에요." 테스트 57/57(사분면 배치·우세 판정·전략 문장·동률).

- 화면: 「지금 기분은 어느 쪽인가요?」 인형 5 → 고르면 「지금 몸은 어느 쪽인가요?」 인형 5 → 디렉팅(기분·몸 칩 + 글 + 각주 "SAM으로 묻고 Russell 원형 모델로 읽었어요. 검사 결과가 아니라 자가보고"). `MIND_DAYS` 목업을 기분·긴장 값으로, 기록 탭 표시도 「기분 조금 좋음 · 긴장 느긋함」.

- 4명 인사말에서 "안녕하세요, 옆반이에요" · "수석교사예요" · "동기예요" · "상담교사예요" 를 걷어냈다 — 문장은 그대로, 자기소개만 없앰. 인물 설정(persona)도 "이름도 직함도 밝히지 않는다(…자기소개 금지)" 로 바꿔 LLM 답변에서도 역할 이름이 안 나오게.
- 가드 테스트: 인사말에 안녕하세요·옆반·수석교사·동기·상담교사·상담사 없음 + persona 에 직함 금지 문구 있음. 테스트 54/54 · tsc 0.
- (같은 건 후속) 실서버에 「누구세요?」를 던지니 옆반 캐릭터가 "저 옆 반이에요, 매일 복도에서 마주치잖아요" 라고 답했다(인사말만 고쳐서는 LLM 답변은 못 막는다). → `SYSTEM_CORE` 에 공통 규칙 「자기소개 금지 — 누구냐고 물어도 역할·직함·관계를 말하지 않고 '편하게 이야기 나누는 사람'이라고만」 추가, 옆반 persona 금지어에 '옆 반'·'복도에서 마주치는' 보강. 배포 후 4명 재확인.

## 후속 21 — 「마음과 대화」 카드 문구 (사용자 지시: 스트레스·답답함·억울함은 거부감)
- "스트레스, 답답함, 억울함 — 터놓고 말해도 되는 자리예요…" → **"일상대화를 편하게 할 수 있어요. 오늘 하루 선생님의 마음을 열어보세요."** 앱에 사용자 이름이 없어(로그인 화면에 이름 입력 없음 · 전부 「선생님」 호칭) 「누구님」 자리는 「선생님」으로.

## 후속 22 — 인사말 4명 통일 (사용자 지시: 질문으로 갈라 두지 말 것)
- 첫 인사말을 `INTRO` 상수 하나로: **"안녕하세요 선생님, 오늘 어떤 하루였어요? 하고 싶은 말이 있으시면 편하게 말해 주세요."** 4명 전부 같은 문장(캐릭터 차이는 답변 말투·관점에만). 가드 테스트가 `intro === INTRO` 를 못박음. 54/54 · tsc 0.

## 후속 23 — 마음 건강 시트를 두 섹션이 화면을 꽉 채우게 (사용자 지시)
- 카드 두 장 + 빈 여백 → 위 「마음과 대화」(제목·문구·아바타 4개 크게) / 구분선 / 아래 「오늘의 마음카드」(그림 92px·제목·문구·「그림 고르러 가기」 알약). 두 섹션 `flex:1` 로 반씩, 세로가 모자란 폰에서만 스크롤(`min-height:230px`). 아래 섹션은 통째로 버튼. 각주("두 가지 모두 선택입니다…") 제거.
- Chrome 실측: 두 섹션·구분선 렌더 · 마음카드 탭 → 그림 시트 · 아바타 탭 → 대화(통일 인사말). 콘솔 에러 0 · 54/54 · tsc 0.
- (후속) 구분선 2px 로 진하게(`#c9d5dc`) · 「그림 고르러 가기 ›」 알약 삭제(섹션 전체가 버튼이라 중복) · 「오늘의 마음카드」 제목을 그림 위로. Chrome 실측 OK.

## 후속 24 — 기록 탭 「시간별로 얼마나 하셨나요」 애매함 (사용자 지적: 앞은 분·옆은 횟수라 뭘 몇 분 몇 회 한 건지 모른다)
- 제목 **「몇 분짜리를 몇 번 하셨나요」** + 부제 "몸풀기 한 편의 길이 기준 · 횟수와 합계 시간". 줄 = 「3분짜리 ▬▬ 7회 · 21분」(횟수 × 길이 = 합계 분을 함께). 위 카드 「이번 주 실행 14회 · 모두 50분」과 합이 맞는다(4+7+1+2 · 4+21+5+20). Chrome 실측 OK · tsc 0.

## 후속 25 — 프로그램은 전부 1분 (사용자: "현재는 전부 1분짜리야 그런데 무슨 10분짜리까지 있냐")
- `PROGRAMS` 15개 `min` 전부 1(영상 한 편 = 1분·앱이 1분에서 멈춤과 일치). 「3분 숨 고르기」→「숨 고르기」. 걷기 2개도 기본 1분(타이머에서 늘릴 수 있음).
- 기록 탭 「몇 분짜리를 몇 번 하셨나요」 카드 **삭제**(전부 1분이라 뜻이 없다) + `byMin`/`maxByMin` 배관 제거. 「이번 주 실행 14회 · 모두 14분」. 과거 주 합계(51/38/64분)는 1분 단위 규모(11/8/16)로. 문구: 라이브러리 「1~10분」→「한 편 1분」, 몸 솔루션 "3분짜리를 가장 자주"→"목·어깨 쪽을 가장 자주".
- Chrome 실측: 라이브러리 15개 칩 전부 1분 · 기록 탭 차트 없음·14회/14분. 54/54 · tsc 0.
- (후속) 「어떤 걸 하셨나요」 = 스트레칭 이름 + 「N회」 글자(사용자 제안) — 1분 칩·점 표시 삭제. AI 제안의 "3분 걷기 한 번 더" 잔재도 1분 기준으로.
