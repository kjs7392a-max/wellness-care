# 2026-11-20 — 마음 쉼터 「함께 머무는 사람」 (캐릭터 · 서로 보이기 · 대화 · 장면 속 움직임)

## 지시(사용자)
- 「계정 없이 둘러보기」로 들어온 사람도 **자기 캐릭터를 고르고**, 같은 방(불당·교회·성당·명상룸)에 들어온 사람끼리 **서로 보이고 채팅**(단체 + 1:1)할 수 있게.
- 백엔드는 **Supabase 새 프로젝트**, 캐릭터는 **사람 캐릭터**(직접 그림).
- (이어서) "메타공간에 캐릭터가 움직일 수 있게 — 들어오는 게 보이고 퇴장할 때는 나가는 것처럼" → **움직임까지 넣고 한 번에 배포**.

## 한 것
### 연결(Supabase Realtime)
- `space-config.ts` — 프로젝트 URL·**publishable 키만**(브라우저용 공개 키). 🚫 secret·service_role 키 금지(가드).
- `space-realtime.ts` — 익명 로그인(`signInAnonymously`) · 계정 사용자는 loginId 별 localStorage, 둘러보기는 **sessionStorage(이 탭 동안만)**.
  - 방 채널 `space:<room>` · 1:1 채널 `dm:<room>:<작은uid>:<큰uid>` — **모두 private 채널**(RLS: `docs/space-realtime-setup.sql`, Supabase 에서 실행 완료).
  - Presence 로 함께 있는 사람(`{uid, avatar, since, seat}`) · Broadcast 로 메시지. `moveTo(seat)` 로 자리 다시 알림.
- 신고는 `space_reports` 테이블에 **넣기만**(읽기 권한 없음 — 대시보드 Table Editor 에서 확인).

### 안전
- 보내기 전 `checkOutgoing`: 빈 글·120자 초과·연속 전송(1초 1개·1분 15개)·**위험한 말(risk L2)은 보내지 않고 상담 안내(109 등)**.
- 연락처는 가림(`(연락처 가림)`) · 받은 메시지도 다시 검사해 위험하면 "안전을 위해 가려진 메시지예요."
- 차단·신고(신고하면 차단도) · 🚫 메시지는 어디에도 저장하지 않음(기기에 쓰는 건 고른 캐릭터뿐).

### 캐릭터(`space-avatars.ts`)
- 8명: 하늘·바다·새벽·노을·솔·별·이슬·바람 — 동그란 얼굴 그림 + **장면용 전신**(`figureSvg(id, "sit" | "walk")`).
  - 걷는 모습은 그림 안 CSS 로 팔다리가 흔들림(±15°) · 움직임 줄이기 설정이면 멈춤.

### 장면 속 움직임(`space-seats.ts` + `SpaceTogether.tsx` `SpaceScene`)
- 방마다 **자리**(영상 기준 좌표)와 **입구**를 정함 — 명상룸은 영상 속 사람 자리를 피해 방석 자리, 불당은 좌복, 교회·성당은 의자.
  - 자리는 영상이 화면에 맞춰진 자리(`fitRoomVideo` rect)로 옮겨 그림 → 화면 크기가 달라도 같은 자리.
- `resolveSeats` — **먼저 온 사람(since → uid) 순**으로 원하는 자리, 없으면 첫 빈자리, 다 차면 장면엔 없고 목록에만. 모두가 같은 목록(차단한 사람 포함)으로 계산 → 기기마다 같은 답.
- 들어오면: 나보다 늦게 온 사람(그리고 나)은 **입구에서 걸어 들어와 앉음** · 먼저 있던 사람은 앉아 있는 채로.
- 나가면(presence 에서 사라지면): **입구로 걸어 나가며 흐려지며 사라짐**.
- 빈자리(점선 동그라미)를 누르면 내 캐릭터가 걸어가 앉고, 다른 사람 화면에도 그대로 보임.
- 다른 사람 캐릭터를 누르면 대화 시트가 열리고 그 사람 메뉴(1:1 대화·차단·신고).
- 단체 대화를 보내면 그 캐릭터 머리 위에 **말풍선 4.5초**(26자에서 자름). 1:1·가려진 메시지는 말풍선 없음.
- 차단한 사람은 장면·목록 모두에서 안 보임(자리는 계산상 그대로 비워 둠).

# (같은 날) 캐릭터 방향 · 이름표 위치

## 지시(사용자)
"캐릭터 이름은 머리 위에 두고, 불당·교회·성당은 앞을 보고 있어야 하고, 명상룸은 마주 보고 있어야 하잖아."

## 한 것
- `space-avatars.ts` — 전신 그림을 **앞·뒤·옆** × 앉음·걸음으로(`figureSvg(id, pose, facing)`).
  - 뒷모습: 얼굴 없이 귀·뒷머리(긴 머리는 등까지, 올림머리는 쪽머리, 흰머리는 결) · 앉으면 손은 앞이라 안 보임.
  - 옆모습: 오른쪽을 봄(눈 하나·코·입) · 왼쪽을 볼 땐 화면에서 좌우 뒤집기.
- `space-seats.ts` — 방마다 `face`: 불당·교회·성당 = `forward`(앞을 봄 → 뒷모습) · 명상룸 = `center`(가운데를 향해 **서로 마주 봄** → 왼쪽 자리는 오른쪽, 오른쪽 자리는 왼쪽).
  - `walkHeading` — 걸을 땐 가는 쪽: 옆으로 가면 옆모습 · 안쪽(위)으로 들어가면 뒷모습 · 화면 쪽(아래)으로 나오면 앞모습.
- 장면: 이름표를 **머리 바로 위**로(그림 위쪽 빈칸만큼 내림), 말풍선은 이름표 위.

## 검증

- 미리보기 두 탭: 명상룸 서로 마주 봄 · 불당은 아래에서 뒷모습으로 걸어 들어와 앉음 · 교회는 두 사람 다 뒷모습 · 나갈 땐 앞모습으로 걸어 나오며 사라짐 → main 배포.

# (같은 날) 교회·성당은 장의자에 앉은 모습

## 지시(사용자)
"성당이나 교회에 등이 보이는데, 보면 좌식에 앉아 있는 것같이 보여."

## 한 것
- 방마다 `sitOn`: 명상룸·불당 = `floor`(책상다리) · 교회·성당 = `pew`.
- 그림 `pew` 자세(앞·뒤·옆): 다리·손 없이 **머리·어깨·가슴께까지만**(100×104) — 그 아래는 앞 의자 등받이에 가린 것처럼 잘림 · 바닥 그림자 없음.
- 자리 재실측(포스터 프레임 확대 + 격자): 그림 아래 끝이 **장의자 등받이 윗선**에 오도록.

- 테스트: 통로·영상 속 사람·화면 가장자리(x .15~.88) 피하기 · 성당만 최소 5자리.

- 다른 사람 캐릭터를 누르면 지금처럼 1:1·차단·신고 메뉴.

# (같은 날) 자리 고르기 없애기 · 걷는 모습

## 지시(사용자)
"너무 복잡한데 자리를 옮기거나 할 필요는 없을 것 같아. 그 기능은 빼고 원은 아예 안 보이게, 움직임이 귀신도 아니고 스르르 움직이게 하지 말고 좀 더 세밀하게 걷는 것처럼."

## 한 것
- 🚫 자리 고르기 기능·빈자리 원 제거 — 자리는 먼저 온 순으로 자동(겹쳐 밀리면 통로를 거쳐 새 자리로 걸어감).
- 걷는 그림(`space-avatars.ts` `walkStyle`, 한 박자 0.52초에 두 걸음):
  - 옆모습: 허벅지·정강이·위팔·아래팔을 따로 돌림 — 디딜 땐 다리를 펴고, 뒤로 차올린 뒤 무릎을 접어 내딛음 · 팔은 반대 다리와 함께.
  - 앞·뒷모습: 내딛는/드는 다리를 길이(원근)로 · 몸이 디딘 발 쪽으로 살짝 실림.
  - 몸이 발 닿을 때 내려가고 한 발로 설 때 올라감.
- 이동 빠르기를 캐릭터 키에 맞춤(키 0.9배/초 — 한 걸음 ≈ 그림 속 다리 벌림) → 발이 바닥에서 미끄러져 보이지 않게. 멀리 있는 작은 사람은 화면에서 더 천천히.
- 길 따라 걷기(`routeIn/routeOut/routeMove`): 교회·성당은 통로로 올라가 → 줄 끝 → 옆으로 들어가 앉음(줄 안에선 아랫몸이 등받이에 가림). 나갈 땐 일어나 거꾸로.
- 🚫 흐려지며 사라지기 없음 — 입구를 화면 밖으로 밀어 걸어서 나감.

## 검증

# (같은 날) 들어올 때 자리 고르기

## 지시(사용자)
"본인이 앉고 싶은 자리에 앉을 수 있는 건가?" → "보통 처음 들어올 때 원형을 줘야지 자기가 고를 수 있겠네."

## 한 것
- 방에 들어오면 **빈자리만 원으로**(살짝 깜빡임) + 「앉고 싶은 자리를 눌러 주세요」. 하나를 누르면 원이 사라지고 그 자리로 걸어 들어가 앉는다.
- 고르는 동안은 다른 사람 장면에 안 나오고 자리 계산에서도 빠진다(presence `picking`) — 고른 순간(`at`)부터 모두에게 걸어 들어오는 모습이 보인다. 대화 알약의 사람 수엔 바로 들어간다.
- 안 고르면 20초 뒤 앞쪽 빈자리로 · 자리가 다 찼으면 원 없이 목록에만 · 앉은 뒤엔 옮기기 없음(앞서 사용자 지시).
- 같은 자리를 동시에 고르면 먼저 들어온 사람이 앉고, 밀린 사람은 통로를 거쳐 다른 빈자리로.

## 검증
- 테스트 **582 통과** · tsc 0 · next build 통과.
- 미리보기 두 탭: A 입장 → 원 7개 → 오른쪽 장의자 선택 → 걸어 들어가 앉음 · B 입장 → A 자리 빼고 원 6개, A 화면엔 B 아직 안 보임 → B가 고르자 A 화면에서 통로로 걸어 들어와 앉음(9.4초) · 안 고르면 20초 뒤 자동으로 앉음 → main 배포.
