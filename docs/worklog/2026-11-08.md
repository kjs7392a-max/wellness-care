- 파일 `public/wellness/space/{temple,church,cathedral,meditation}.{mp4,jpg}`.
  - ★원본 불당·교회·성당 = **HEVC Main10(10비트)** — 안드로이드·크롬 다수에서 재생 안 될 수 있다(실측 ffprobe).
    → **H.264 8비트 CRF 19 · faststart** 로 변환. 원본 대비 SSIM 0.991~0.992, 용량 10.2/7.6/7.2MB → 2.2/1.4/1.6MB.
  - 명상룸 = 원본 H.264 720p·AAC → 영상만 CRF 19 재인코딩, **소리는 그대로 복사**(SSIM 0.9917, 6.8 → 2.2MB). 자막 글자 선명도 확인.
  - 포스터(jpg) = 각 영상 0초 프레임(540×960) — 로딩 중 화면·고르는 화면 사진·남는 띠의 흐린 배경.
- `space.ts`(순수) — 공간 넷 · 지켜야 할 칸(safe: 프레임 0/2.5/5/7.5/9.9초 실측) · `fitRoomVideo` · 소리 설정.
  - 기본 = 화면 꽉 채움(cover). 지켜야 할 칸이 머리줄(위 100px) 아래 화면 밖으로 나가면 그만큼만 줄이거나 민다. 남는 띠 = 흐린 포스터.
  - 성당: 오른쪽 의자 사람(x .75–.89) 때문에 좁은 폰에서 왼쪽으로 몇 px 민다. 명상룸: 자막 상자(x .055–.945)가 들어오게 조금 줄인다(위아래 띠).
- `SpaceSheet.tsx` — 고르는 화면 + 공간 화면. 머리줄엔 ‹·공간 이름만(명상룸 안내 글 없음). 명상룸만 오른쪽 위에 소리 단추+음량 막대.
  - 소리 설정은 기기에 저장(`wellness-care:space-sound:v1`, 기본 켜짐·60%). 소리 있는 자동 재생이 막히면 소리 끄고 재생 + 단추 「소리 켜기」.
  - iOS 사파리는 `video.volume` 을 못 바꿔서, 그런 기기에서만 Web Audio GainNode 로 음량(AudioContext 는 카드 누르는 순간 준비).
