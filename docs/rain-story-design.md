# 빗속의 나 v2 — PDF 채점 요소를 응용한 그림 조합

## 원자료와 응용 범위

중원대학교 유경미 교수, 미술심리진단평가 5장 ‘빗속의 사람(PITR) 그림검사’ 강의 PDF. 원자료는 **직접 그린 그림**을 관찰·측정하는 검사이며, 본 앱은 **현재의 부담·영향·보호를 그림으로 직접 선택하는 자기탐색 콘텐츠**다. 직접 그림과 완성 이미지 선택의 측정 타당성이 같다고 주장하지 않는다. 선택형의 점수는 원검사 점수·임상 지수·우울 지수가 아니다.

| 앱에서 고르는 그림 | 참고한 원자료 | 앱의 적용 |
|---|---|---|
| 가는 비 / 꾸준한 비 / 세찬 비 | 13쪽 S1 비의 양, S2 비의 세기 | 두 항목의 방향만 참고해 한 축으로 구성. 선 개수·인치 기준을 그대로 사용하지 않음 |
| 거의 닿지 않음 / 일부 닿음 / 온몸으로 맞음 | 14쪽 S5 비와 사람의 접촉 | 선택자가 직접 느끼는 영향을 세 단계로 표현 |
| 없음 / 있으나 부족 / 충분한 보호 | 18~19쪽 R1~R5 보호물과 적절성, 특히 R4/R5 | 도움·방법·여유의 현재 가용성을 세 단계로 표현 |
| 부담과 보호의 관계 | 17쪽 스트레스 총점 방향, 21쪽 대처자원 총점 방향과 차이 해석 | 원검사 합계 대신 아래의 앱 전용 정규화 규칙 사용 |

얼굴·인물 크기·위치·선의 질감, 구름·번개·웅덩이의 개수 및 거리 등 원자료의 나머지 항목은 앱에서 측정하지 않는다. 선택하지 않은 항목을 중립값으로 임의 대입하지 않는다. 우울·성격·인간관계를 판정하지 않는다.

## 내부 조합 규칙 — UI에는 미표시

각 선택 축은 원자료 방향을 참고해 1·2·3의 순서값으로 코딩한다. 비와 접촉 두 축의 **평균**을 부담 표현값으로, 보호 축을 자원 표현값으로 사용한다. 둘의 범위를 맞춘 다음 `보호 - 부담 평균`의 부호를 비교한다. 이는 원검사의 `R 총점 - S 총점` 공식 자체가 아니라 선택형용 설계 규칙이다. 임상 규준·절단점이나 검증된 심리 측정값으로 사용하지 않는다.

- 양수: 부담보다 나를 지킬 여지가 크게 표현된 조합
- 음수: 받는 영향에 비해 지금 가용한 보호가 적게 표현된 조합
- 같음: 부담과 보호의 크기가 비슷한 조합. 둘 다 작은 경우와 둘 다 큰 경우를 서로 다르게 해설

거센 비+직접 접촉 거의 없음, 가는 비+온몸 접촉은 상황 크기와 개인 영향의 차이를 따로 해설한다. 온몸 접촉+충분한 보호는 ‘이미 영향을 받는 느낌’과 ‘활용할 도움이 있다는 느낌’이 공존하는 응답으로 설명한다. 도움의 존재를 곧바로 영향 없음으로 치환하지 않는다.

세 축을 각각 해설하고 조합 관계를 연결하므로 27개 조합 모두 서로 다른 한 문단이 나온다. 반환 결과는 제목과 해설 문자열만이며, 내부 숫자·등급·프로필 코드·원점수·통계를 반환하거나 DOM에 렌더링하지 않는다. 관리자용 평가 저장도 추가하지 않는다.

## UX와 데이터

비 선택 → 내가 받는 영향 선택 → 지금 쓸 수 있는 보호 선택 → 세 그림 요약과 오늘의 마음 해설. 예전 4장 장면 선택·감정 문장·기분/스트레스/에너지 설문·이야기 입력·AI 읽기 모두 이 파트에서 제거했다. 같은 인물의 표정이나 배경을 비교 항목으로 채점하지 않는다. 각 단계에서는 해당 축의 차이에만 답하도록 안내한다.

답변은 version 2 구조의 현재 React 세션에만 남는다. 결과를 여는 데 API·AI·Redis 호출이 없고 유료 비용도 발생하지 않는다. 사용자 요청으로 제거한 공간·대화 활동 버튼은 복구하지 않는다. 선택 수정, 처음부터 다시 하기, 테스트 선택 화면으로 돌아가기만 제공한다. 원자료를 참고한 선택형이며 정식 검사·진단이 아니라는 안내를 결과에 표시한다.

## 이미지

imagegen 기본 도구로 제작한 세 장의 가로 3분할 수채화 비교 이미지이며 각각 정사각형 장면 세 개를 포함한다. 원본 PNG는 보존하고 프로젝트에서는 크기 변경·장면 편집 없이 JPEG 형식으로 최적화했다.

- `public/wellness/rain-story/pitr-v2-rain.jpg`
- `public/wellness/rain-story/pitr-v2-exposure.jpg`
- `public/wellness/rain-story/pitr-v2-protection.jpg`

동일 단계 안에서는 인물의 크기·자세·배경을 유사하게 유지하고 질문에 해당하는 비·접촉·보호 차이를 비교한다. 성별과 얼굴의 차이는 채점 요소가 아니다. 과거 이미지 파일은 다른 참조를 깨지 않도록 보존한다.
