## 흐름

각 직접 응답은 건너뛸 수 있다. 영향 요인은 선택 사항이며 복수 선택 가능하다. 점수·등급·유형·우울 수준을 사용자 결과에 표시하지 않는다. 이미지의 선택과 영향 요인은 평가나 추천 분기에 사용하지 않는다. 추천은 명시적인 당일 상태 응답으로만 나누며, 응답을 모두 건너뛰면 일반적인 쉼을 제안한다.

## 연결

- 스트레스가 많다는 직접 응답: 마음쉼터
- 남은 힘이 적다는 직접 응답: 가볍게 쉬는 안내와 마음쉼터
- 기분이 가라앉았다는 직접 응답: 대화
- 기분·힘이 보통 이상이고 체감 스트레스가 보통 이하: 오늘의 산책(안전 확인 완료, 제한·보류 없음일 때만)

결과 화면의 공간·대화 등 활동 연결 버튼과 안내 영역은 사용자 요청으로 제거했다. 결과를 보는 동작에서 네트워크 요청은 발생하지 않는다.
